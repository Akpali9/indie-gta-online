# Indie GTA Studio Pack

A Unity-based GTA-style open world starter project.

## FEATURES
- Player movement system
- Vehicle system
- Economy system
- Mission system
- AI police system
- Save/Load system
- Multiplayer-ready structure

## HOW TO RUN
1. Open Unity Hub
2. Open project folder
3. Load Scene: City.unity
4. Press Play

## REQUIREMENTS
- Unity 2022 LTS or higher
- TextMeshPro package
